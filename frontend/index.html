Adaptive learning for Classes 6 to 10, Maths and Science, for CBSE, ICSE and the Telangana State Board. Study chapter by chapter, prepare for tests by date, and practise for marks. The student phone works offline. Sample classmates only, no real student data.

Chapter names were gathered from public textbook and syllabus pages and need a teacher’s check before real use. Each chapter maps to topics in one shared prerequisite graph, so gaps from earlier classes are found whatever the board. Questions and lessons were written for this project and checked in a blind review, but a teacher should still review them. Hindi and Telugu text is a draft for review. Answers are saved on this phone first and synced to the server when a connection is available.
