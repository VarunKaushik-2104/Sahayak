About Sahayak

Sahayak (సహాయక్, सहायक: "helper") is a free web app that finds the earlier topic behind a student's mistake and practises it. It was built by Team WIN R, students at Gokaraju Lailavathi Engineering College, for the Adaptive Learning for Classes 6 to 10 challenge at Code Kernel '26.

What is built

  • A Python (FastAPI) server with a database for students, schools, answers and mastery.
  • An installable offline-first web app for students, with a teacher dashboard and a parent view.
  • {{ n_topics }} topics and {{ n_questions }} questions, with chapter lists for CBSE, ICSE and the Telangana State Board.
  • This website, with one page for every topic.

The code is open: github.com/VarunKaushik-2104/Sahayak.

What has not been proven yet

  • The mastery model uses sensible default numbers. They have not been fitted to a large set of real student answers, and no classroom trial has been run.
  • Questions and lessons were written for this project and checked in a blind review. A teacher should still read them before use.
  • Chapter names come from public pages and need a teacher's check each year.
  • Hindi and Telugu text is a draft for native-speaker review.
  • Only Maths and Science, Classes 6 to 10, are covered.

Teachers or students who want to help review content: get in touch.
